# 树洞讨论与全功能验收报告

日期：2026-11-08至11-09。黑榜补足与同乡讨论已实现并发布，两个公开入口已读回新构建；本机、真实后端及公网交互验收均通过。

## 结果与使用方式

先完成价格逐元长按、压缩价格框和单一用户治理入口并上线后，再执行本阶段。当前Web增加树洞双入口：黑榜避雷、同乡留言；四项底栏顺序不变，沿用既有奶油底、蓝黄配色、卡片及按钮。

同乡留言提供同乡交流/校园生活/吃喝吐槽分类，公开主题、同省同市筛选、我的发帖及我的回复；标题、正文、分类必填，配图选填。楼层支持顺序回复、引用、20层分页及消息定位某一楼；作者修改或撤回主题、撤回楼层，撤回和隐藏留下占位，不重新编号。管理员填写原因隐藏/恢复、处理举报并保留快照及审计；不能恢复作者主动撤回内容。楼主和被回复者通过原互动消息收到提醒。

这是与现有CloudBase函数相容的异步公开讨论；家乡为用户自填信息，不作为实名认证或私密群组。未引入即时聊天服务，也不据此宣称满足所有公开运营资格。具体店铺消费记录仍走黑榜事实填写与先审后发。

## 黑榜审核与修复

1. 补全问题类别、正文、消费确认的必填提示和提交前拦截，非法/未来日期拒绝。
2. 修复黑榜保存、举报回执仅认编号的问题：同编号改内容拒绝，正确重试不生成重复记录。
3. 原消息和管理举报只读取首20条，现按原游标遍历；已处理举报可查看、已读和清理，不把待处理当成已解决。
4. 实际云端测试发现退回后重交时携带不可写的`_id`，已在黑榜及新讨论的文档写入层排除；内存测试库增加同样限制，防止本机假通过。
5. 举报和处理说明允许引用“广告”等待核实词语；讨论以纯文本渲染，拒绝控制字符，不执行HTML。
6. 修复树洞明确`tab=black`仍受上次论坛记忆覆盖；切换双入口会同步网址，刷新保持正确分类。
