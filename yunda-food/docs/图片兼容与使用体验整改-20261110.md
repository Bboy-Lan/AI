## 一、图片上传与苹果照片（HEIC/HEIF）

新增 `src/domain/image-policy.ts` 与 `src/services/image.ts`，把头像、推荐配图、黑榜配图、树洞配图统一到一个入口 `prepareImage(file,purpose)`：

- 解码顺序先 `createImageBitmap({imageOrientation:'from-image'})`，失败回落 `<img>`，仍失败且判定为 HEIC/HEIF（MIME 或后缀）时用懒加载的 `heic2any` 解码，日常浏览不下载这 1.35MB 分块。
- 输出统一走 canvas `toBlob`，按 webp→jpeg→png 回退，并按**实际** `Blob.type` 生成扩展名；服务端只接受 jpg/png/webp，因此 HEIC 必须先在浏览器转码，服务端仍拒绝 `extension=heic`（云端已验证）。
- 按用途收敛：头像长边 768、目标 320KB、上限 900KB；普通照片长边 2048（长图 2560）、目标 1.6MB；证据类长截图长边 4096、优先 PNG 保文字。
- 多轮 quality/scale 收敛，串行队列（并发 1）避免多张同时解码爆内存；`classifyImageError` 按配额→体积→解码→登录→网络排序给出可理解提示。
- 组图上传改为逐张串行，失败项单独列在 `.upload-failures` 并可只重试失败项，成功项保留；`accept` 增加 `.heic,.heif`。评价与反馈的上传路径未改动，ReviewDesk 仍只支持重排与移除。

真实 HEIC 样张（718KB，`ftyp mif1/heic`）在浏览器内解码为 `image/webp 1280x854 310KB`，头像策略输出 `45KB webp`，扩展名 `webp` 与真实类型一致。

## 二、"我的"→ Excel 导出

新增 `src/domain/export-config.ts`、`src/services/xlsx.ts`、`src/pages/ExportPage.tsx`，"我的"页面新增入口"导出 Excel · 选取美食与字段"。四步流程：选取范围（我的投稿/我的收藏）、搜索与分类/地点筛选、全选当前筛选结果、列配置（启用/停用、上下移、改名）与临时备注、预览后导出。

- 用 ExcelJS 真实生成 `.xlsx`（懒加载 929KB 分块），冻结首行、按字段设列宽，价格列是数值单元格。
- 价格沿用展示口径（1～999 整数元）；`priceBasis` 输出单份/人均/未标注，不猜造。
- 备注默认取投稿说明，编辑只作用于本次导出，不改云端记录。
- 文本单元格全部走 `excelSafeText`（去控制字符、限 1000 字），任何文本都不写成公式，`=`/`+`/`-`/`@` 开头也只是文本。
- 手机与微信保存路径在页面内提示：下载记录/文件传输助手，或浏览器"分享 → 存储到文件"。

openpyxl 抽查演示导出：`sheet 我的投稿`、范围 `A1:F3`、冻结 `A2`、价格列 `n` 类型、无 `<f>` 公式节点、无外部链接、列宽 22/20/34/13/11/32 与配置一致。

## 三、审核标签

- `reviewTagOf` 在客户端与服务端使用同一规则：`reviewTag` 缺失时按真实发布状态推导（`public/published/approved → approved`，`hidden → blocked`，`returned/rejected → changes`），不再默认"待审核"。
- `ReviewBadge` 对 `approved` 恒不渲染，只有作者与管理员看到其余真实状态；审核台作为管理员界面显式开启 `showApproved` 读取真实状态。
- 服务端 `whereTag` 修正：`pending` 只匹配 `['pending']`，新增 `approved → ['published','public']`，公开老记录不再堆在待审核队列。

## 五、管理员不再被自己的公告提醒

服务端 `popupEligible` 对管理员恒为 false，`assertBasicNotice` 对管理员直接放行（仍可读、可管理公告），普通用户逻辑不变。**本轮云端验收发现一处真实缺口**：`announcements` 动作此前没有把运行时管理员标志传给公告模块，导致接口对管理员也返回 `popupEligible=true`；本地单测只覆盖了 `adminNotices` 分支所以没有暴露。已修为 `f('listAnnouncements',{admin:Boolean(admin)})`，并同步修正演示环境的同一判定，补了演示模式回归用例。云端复验：管理员该公告 `configuredPopupEnabled=true / popupEligible=false`，普通用户 `popupEligible=true`，关闭后普通用户列表立即不含该公告。

## 六、店名独立维护

`storeName` 从提交、编辑、服务端校验落库（`text(payload.storeName,40)`，非空需 ≥2 字，`assertSafeText` 过滤重复字符与广告词）、DTO、列表/详情、首页搜索（`discovery` 关键词匹配纳入店名）到导出一列贯通：

- 单字店名被服务端拒绝；超长按上限收敛；编辑不传保留原值、传空串才清空。
- 老记录没有店名时输出空字符串，不猜造。
- 发布/编辑表单新增"店名 / 摊位名（选填）"，详情页显示"店名 · xxx"。

## 七、头像可点击放大
