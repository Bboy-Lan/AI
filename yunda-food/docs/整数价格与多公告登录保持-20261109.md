# 整数价格、首次使用、多公告与保持登录

2026-11-09，用户明确要求首次注册账号密码、昵称头像和省市后，强制查看基本须知；此要求覆盖旧游客直接浏览的规则。仅修改隔离新Web，原始小程序/旧H5/冻结参考只读。

## 最终规则

价格只接受1～999整数元，输入/数字键盘/加减按钮与长按均逐元；前后端拒绝新的小数提交。历史小数只在展示与编辑初值四舍五入并限制有效边界，不批量覆盖真实原记录。原口味、筛选、人均/单份口径不变。

首次流程为邮箱账号与密码（邮箱验证）→昵称、头像、省市→基本使用须知→主程序。头像和昵称/省市缺任一项不能保存，资料未完成不提前弹公告；基本须知未知晓时服务端也拦截投稿/评价/收藏等后续操作。受限账号原反馈与申诉通道保留。

基本须知与各条通知独立管理。管理员从首页公告或用户治理的公告管理进入；可新增通知、保留草稿/撤下、设置自动弹出或仅在公告中心展示、开始/截止时间，以及单条主动重提醒。基本须知始终向首次用户弹出；只改文字默认不打扰已读用户。勾选重提醒才开启本条新一轮知晓，不影响其他公告。

需要知晓的公告按基本须知优先逐条显示，只能点知晓完成，遮罩和Esc不能跳过。按真实账号、公告ID与提醒版本在云端记录已读，不依赖sessionStorage。旧单公告已读记录兼容；同一账号换设备登录也能恢复已读。草稿/未到时间/已过期/撤下公告不对普通用户显示，管理员可查看。版本冲突保留输入，同编号同内容幂等、不同内容拒绝，并记录私有编辑审计。

## 登录保持与微信边界

安装的CloudBase JS SDK为3.11.0，显式配置本地登录持久化。恢复登录失败时区分网络故障和凭证失效；网络故障不悄悄创建匿名身份覆盖旧会话。令牌刷新交给SDK，网页不保存明文密码；已过期的登录转到重新登录入口。首次未登录先查本地会话，无会话时零匿名登录/云身份请求即可显示注册页；资料未完成不加载整批美食图片。认证SDK按需加载，注册首屏主脚本由约1.43MB降到约577KB（gzip约175KB），认证资源单独分块、需要登录时才下载。启动12秒仍未完成会显示恢复提示；脚本下载失败有静态提示与重试按钮。

使用同一设备、同一浏览器容器、同一网址，通常可直接恢复会话；主动退出、清理站点数据、隐私模式、换到外部浏览器/设备/域名或登录凭证失效时需要重新登录。昵称头像和省市、公告已读在云端，不需重新填写。主站和备用域名不共享本地登录存储，分别登录后可读同一份云端资料。微信内置浏览器和系统浏览器是不同容器，不能承诺两者共享登录。

真实测试已验证离开原页面后新开独立标签恢复同一账号、刷新仍保持、实际调用SDK刷新令牌成功、退出再登录资料和已读仍在、未存明文密码。测试是桌面Chromium及同浏览器新标签，不是微信/iOS/Android实体机，也没有宣称关闭微信进程后的固定保留天数。没有验证真实邮件收信。SDK会话接口参考[CloudBase认证概述](https://docs.cloudbase.net/api-reference/webv3/authentication)，本次保持登录结论以实际浏览器验证为准，不引用2.x的30天规则作为3.x承诺。
