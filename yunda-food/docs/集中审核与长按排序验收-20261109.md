# 集中审核与长按排序

2026-11-09，用户确认方案后执行。新Web工程内实现，原小程序/旧H5/冻结参考只读；不改礼金簿或共享认证。实现、本机/真实云端及两个公网入口发布复验均完成。

## 使用

管理员从“我的 → 用户治理 → 集中审核台”进入；“讨论治理”也使用同一审核组件。推荐、黑榜、讨论主题、评价和楼层五类型统一处理。桌面审核页单独1120px双栏，手机维持原宽度/颜色和卡片。列表64px封面、两行摘要、作者/日期/标签；选中详情仅72px缩略图，点按放大。分页20条，支持类型/状态/搜索/有待处理举报筛选、汇总、全选本页、批量逐条结果和保存并下一条。

审核标签和处理意见分区：待审核、已审核、需修改、违规下架、已删除。封禁指账号，内容使用违规下架。普通推荐/讨论保留现有发布方式，旧公开内容默认待审核，不批量下架或假标已审核；黑榜仍先审后发。要求修改/违规/删除会停止公开。软删除保留原始记录，可由管理员恢复；作者主动撤回不允许恢复。

管理员可修改标题、正文、同类分类和重排/移除原图，保留作者/原发布时间，记录前后版本、操作人和意见并显示管理员已编辑。为保持口味资料一致，推荐跨辣度/甜度类别调整应要求作者修改；管理员不能加入冒充原作者的新图。操作中禁用编辑控件，失败保留意见，服务器版本冲突不能强行覆盖。

作者在原“互动消息”收到标签和意见，可点按要求修改。推荐、黑榜、主题复用原编辑页，楼层新增独立原楼修改页，楼号不变；隐藏内容修改后待审核且不能自行恢复公开。已删除不可再编辑。管理员、图片URL或浏览器传入的角色均不能替代服务端UID/权限校验。

组图共用350ms长按拖动、浮起反馈、换序后首张封面；短按预览，提前滑动取消等待，Esc/取消恢复原序，保留折叠键盘排序菜单。处理延迟/合并输入事件时依据原事件时间判断是否真的达到长按阈值，避免快速滑动被迟到事件误判。

- 54项自动测试通过，含新审核9项和原楼层修改1项；原算法对照另含432种组合。100条跨类型服务器游标、搜索、状态、举报、幂等、版本、并发、审计、通知所有权、软删除/撤回、演示隔离均覆盖。管理员编辑也尊重原必填规则：推荐理由可空、标题上限60字，话题标题至少2字；只调整原图不必编写正文。
- 真实付费云端121项通过。3个临时身份、4张临时图片及关联记录精确清理，私有恢复台账已移除。涵盖原投稿/评价/收藏/黑榜/反馈/申诉/讨论，与新审核/举报筛选/编辑/批量部分失败/本人通知/资料权限/楼层重审闭环；补查空理由和60字推荐标题的管理员编辑。评价下架和恢复后评分人数即时重算。没有改写共享公告。
- 本机41项集中审核、13项补充交互、63项全页面适配、21项原业务回归通过；保存并下一条另有单项烟雾检查。320/390/1440视口居中、无横向溢出，图片缩略尺寸已实测并打开截图检查。
