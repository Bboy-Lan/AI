# 发布精简、店名层级、治理两栏与避雷三字段（2026-11-10）

本轮按用户截图与六点要求落地：地址字段精简、店名层级、按钮改名、治理版面、返回来源、避雷参考字段。

## 1. 推荐地址改成两段式，不再重复同一处地点

- **高校内**：学校（必填）+ 校区 / 校园范围（选填）+ 食堂 / 楼 / 窗口（必填）。
- **高校外**：区域 / 街道（选填）+ 店铺 / 摊位（必填）。
- 删除"地点细节补充"输入；地址区不再出现第三个自由文本框。
- `domain/discovery.ts` 的 `normalize()` 统一合并 `school/campus/venue`（校外 `region/venue`），并做两级去重：
  1. 完全相同的段只留一条；
  2. 一段包含另一段时只留更具体的那条。例：学校"云南大学" + 校区"云南大学东陆校区" → 只显示"云南大学东陆校区"。
- `CloudCompose` 提交时用同一规则生成 `placeText`；服务端仍保留 `school/campus/venue` 原字段，筛选"同乡 / 地点"不受影响。
- 详情地图卡只保留地图名称与坐标，不再重复整段文字地址。

## 2. 图片与推荐理由设为必填（新发布 + 编辑都强制）

- 客户端 `foodRequiredError`：高校内必须有学校；必须有具体窗口/摊位；图片至少 1 张；理由 10–500 字。
- 服务端 `native/food/index.js` 的新建与编辑两处都加同样校验，绕过前端也写不进去。
- 演示仓储 `src/demo/repository.ts` 同步，本地演示与真实云端同一口径。
- 发布页文案直接标明"实拍组图 · 1～3张 必填""想推荐它的理由 · 至少10字 必填"，理由输入带 `minLength=10`。
- 老投稿再次编辑时也要补齐图片与理由，否则保存被拦。

## 3. 店名排在美食名称下方并缩进

- 卡片与详情统一结构：美食名称加粗主标题 → 店名小字（左侧 2px 竖线 + 8px 缩进 + "店名"小标签）→ 地点。
- `.food-title-row strong` 最多两行、`overflow-wrap:anywhere`，价格 `flex:0 0 auto` 不被长名称挤走。
- 列表行 / 格子视图的店名单独收窄为单行省略，不影响紧凑布局。

## 4. 按钮文案精简

- "用户治理 · 待审核 N" → "用户治理"+ 红色数字角标。
- "导出 Excel · 选取美食与字段" → "导出表格"。

## 5. 用户治理改成两栏工作台

- 结构参照集中审核台：左侧入口卡 + 列表，右侧详情/处理面板。
- 宽屏（≥900px）`.app-frame.admin-workspace` 放宽到 980px，`.admin-split` 两栏（列表 + 280–340px 检查器），检查器 `sticky`。
- 手机端单列堆叠，入口卡网格在窄屏降为两列，390/320px 无横向溢出。
- 处理原因、下架/恢复/审核按钮从列表行移到右侧面板，列表行只保留缩略图、标题、状态与摘要，点选后右侧处理。
- 入口卡带计数角标（待审核数），与"我的"页角标同一套红色。

## 6. 从治理页进入子页面，返回回到用户治理

所有治理入口带 `from=admin`，目标页读取后决定返回目标：

| 入口 | 返回 |
| --- | --- |
| 用户反馈 / 举报与不符 / 解禁申请 | `/admin`（否则 `/me`） |
| 黑榜经历详情 | `/admin`（否则 `/treehole`） |
| 讨论话题详情 | `/admin`（否则 `/treehole?tab=forum`） |
| 公告管理 | `/admin`（否则 `/`） |

集中审核台、讨论治理本身固定返回 `/admin`。

## 7. 避雷参考只保留店铺、美食、具体地址

- 表单删除"消费日期"；新增"美食名称（必填）"；"街道 / 摊位"改为"具体地址（必填）"。字段为：店铺名称、美食名称、具体地址、问题类别（1–3 项）、具体经历、现场照片（选填）、亲自消费确认。
- 客户端 `cautionRequiredError`：店铺 → 美食 → 地址（≥2 字）→ 类别 → 经历（10–1000 字）→ 确认。
- 服务端 `native/cautions.js`：新增 `dish`（1–40 字、敏感词校验）；`occurredOn` 改为可选，带值时仍校验格式与"不晚于今天"，老记录不受影响；DTO 增加 `dish`，`date` 保留为空串兼容旧客户端。
- 树洞卡片：美食名做主标题，店名缩进显示，下面具体地址、问题标签、两行摘要，底部作者头像 + 昵称 + 赞数。
- 黑榜详情：标题用美食名，店名用同一套缩进样式，地址单独一行，作者区改成头像 + 昵称 + 家乡；不再显示消费日期。
- 演示数据补 `dish` 与 `storeName`，并让一条演示记录的校区写成"云南大学东陆校区"，用于展示去重效果。
